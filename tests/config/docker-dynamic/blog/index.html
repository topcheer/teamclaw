Introducing PreviewManager

Dynamic web application previews are now available! When a worker submits a deliverable with artifactType "web-app", the controller automatically launches a preview server and makes it accessible through the proxy endpoint.

2026-03-27

How It Works

The worker includes previewCommand and previewCwd in the result contract. PreviewManager spawns a child process, polls health checks, and routes traffic from /api/v1/previews/{id}/ to the running server.
