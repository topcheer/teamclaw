# 需求：旅游酒店预订系统 (Travel & Hotel Booking System)

## 项目概述
开发一个面向中小型旅行社/民宿平台的旅游酒店预订系统，涵盖酒店房型管理、房间库存、预订流程、订单履约和经营分析。需要处理旺季价格波动、连住折扣和多渠道订单归因。

## 核心模块

### 1. 酒店与房型管理
- 酒店信息：名称、星级、城市、地址、设施标签（WiFi/停车场/早餐/泳池/健身房）
- 房型管理：标准间、大床房、双床房、套房、家庭房等
- 房型属性：面积、床型、最多入住人数、朝向、楼层
- 每日价格：基础价格 + 旺季/淡季加价（按日期区间配置）
- 图片管理：每个房型最多 10 张图片，支持封面设置

### 2. 房间库存与日历
- 房间日历：按天维护每个房型的可售数量
- 库存类型：总房间数、已售数、维修占用、预留数
- 日期粒度：支持按日设置价格和库存（节假日特殊价格）
- 不可订日期：满房自动关闭、酒店主动关房
- 批量操作：批量设置某日期区间价格和库存

### 3. 预订管理
- 预订流程：查询房型 → 选择日期 → 检查库存 → 确认预订 → 生成订单
- 入住/退房日期校验：退房日期必须晚于入住日期、最长连住 30 天
- 连住折扣：住 3 晚打 95 折、住 5 晚打 9 折、住 7 晚打 85 折
- 预订状态：`pending` → `confirmed` → `checked_in` → `checked_out` / `cancelled` / `no_show`
- 超时规则：预订后 30 分钟未确认自动释放库存
- 订单号生成：格式 `HTL-YYYYMMDD-XXXX`（日期+序号）

### 4. 价格计算引擎
- 基础房价：房型日价格
- 日期加价：周末 +20%、法定节假日 +50%（可配置）
- 连住折扣：按总晚数阶梯打折
- 优惠券：满减券（满 1000 减 100）、折扣券（9 折券）
- 多优惠组合：连住折扣与优惠券可叠加，取最优价格
- 价格明细：展示每晚价格 + 折扣明细 + 总价

### 5. 渠道与经营分析
- 渠道来源：官网、携程、美团、飞猪、到店
- 入住率统计：按日/周/月计算
- RevPAR（每间可售房收入）：总收入 / 总可售房间数
- 热门房型排行：按预订量排序
- 客单价分析：平均每单金额趋势

## 技术要求
- 使用 Python + FastAPI
- SQLAlchemy ORM + SQLite（单文件）
- Pydantic 模型
- 至少 20 个 API 端点
- 自带种子数据：3 家酒店、15 个房型、90 天日历价格库存、法定节假日配置、模拟预订记录
- 连住折扣和优惠券组合计算逻辑必须正确
- 日期处理注意：使用北京时间，当日 14:00 后入住算当天，12:00 前退房不算当天房费

## 交付标准
- `uvicorn app:app --port 8000` 启动
- 预订-确认-入住-退房流程完整
- 连住折扣 + 日期加价 + 优惠券组合计算正确
- 入住率、RevPAR 统计数据正确
