# 需求：在线教育课程平台 (Online Education Platform)

## 项目概述
开发一个在线教育课程平台后端，支持课程管理、学员注册、学习进度跟踪、作业考试和证书颁发。面向培训机构的日常运营场景。

## 核心模块

### 1. 课程管理
- 课程分类：编程、设计、语言、职业资格等
- 课程信息：标题、描述、讲师、时长、难度（初级/中级/高级）、价格
- 章节管理：每个课程包含多个章节，每章有标题和视频时长
- 课程状态：`draft` → `published` → `archived`

### 2. 学员管理
- 学员注册：手机号 + 验证码（模拟，直接通过）
- 学员画像：已报课程、学习时长、完课率
- 学习卡：课程进度百分比、上次学习位置
- 有效期管理：课程购买后 365 天有效

### 3. 学习记录
- 章节学习记录：每次打开章节记录开始时间和学习时长
- 学习进度计算：已完成章节数 / 总章节数 × 100%
- 连续学习天数统计（断签重计）
- 学习时长排行榜

### 4. 考试系统
- 章节测验：每章结束后的单选题测验（5-10 题）
- 课程期末考试：综合覆盖全部章节
- 自动评分：提交即出分
- 证书颁发：课程考试 ≥ 80 分自动生成电子证书
- 防作弊：考试限 1 次提交机会

### 5. 讲师工作台 API
- 讲师课程列表
- 学员活跃度概览
- 章节完课率统计

## 技术要求
- 使用 Python + FastAPI
- SQLAlchemy ORM + SQLite（单文件）
- Pydantic 模型
- 至少 18 个 API 端点
- 自带种子数据：5 门课程（每门 5-8 章节）、20 个学员、模拟学习记录
- 考试题目从章节数据中生成

## 交付标准
- `uvicorn app:app --port 8000` 启动
- 学习进度计算逻辑正确
- 考试自动评分和证书生成工作
- 排行榜按时长和完课率排序
