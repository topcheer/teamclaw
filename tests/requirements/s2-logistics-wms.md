# 需求：物流仓储管理系统 (Logistics WMS)

## 项目概述
开发一个面向中小型物流公司的仓储管理系统，支持入库/出库/盘点/调拨等核心仓库操作，含供应商管理和库存预警。需要处理批次管理和保质期逻辑。

## 核心模块

### 1. 商品与分类
- 三级分类体系：大类（如食品、电子、日化）→ 子类 → 品类
- 商品 SKU：名称、条码、规格、单位、默认供应商、安全库存
- 商品扩展属性：保质期天数、重量、体积（用于运费估算）

### 2. 入库管理
- 入库单：关联供应商、入库类型（采购入库/退货入库/调拨入库）
- 批次管理：每批入库商品记录批次号、生产日期、到期日期
- 入库审核：提交 → 审核通过 → 库存增加
- 入库明细：商品、数量、单价、批次号、库位

### 3. 出库管理
- 出库单：关联客户/销售订单、出库类型（销售出库/报损出库/调拨出库）
- 先进先出（FIFO）：优先出库最早批次的商品
- 保质期预警：出库时检查距过期天数，临近过期优先出库
- 出库审核：提交 → 审核通过 → 库存扣减

### 4. 库存盘点
- 盘点任务：按仓库/分类创建盘点单
- 盘点录入：实盘数量对比系统库存
- 差异处理：盘盈入库、盘亏出库
- 盘点报告：差异汇总、原因分类

### 5. 库存预警
- 低库存预警：库存量 < 安全库存时触发
- 过期预警：距到期日 < 7 天时触发
- 预警记录和确认机制

### 6. 调拨管理
- 调拨单：源仓库 → 目标仓库
- 调拨在途：状态 `pending` → `in_transit` → `received`
- 在途库存不计入可用库存

## 技术要求
- 使用 Python + FastAPI
- SQLAlchemy ORM + SQLite（单文件）
- Pydantic 模型
- 至少 20 个 API 端点
- 自带种子数据：3 个仓库、50 个商品、10 个供应商、近期入库/出库记录
- 中文界面友好：所有枚举用中文标注

## 交付标准
- `uvicorn app:app --port 8000` 启动
- FIFO 出库逻辑正确：优先消耗最早批次
- 保质期预警和低库存预警正常触发
- 盘点差异计算准确
