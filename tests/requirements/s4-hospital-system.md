# 需求：社区诊所管理系统 (Community Clinic System)

## 项目概述
开发一个社区诊所/社区卫生服务中心的管理系统，涵盖患者挂号、医生排班、诊疗记录、药品库存、收费结算等核心流程。

## 核心模块

### 1. 挂号与预约
- 科室列表：全科、内科、外科、儿科、口腔科、中医科、检验科
- 号源管理：每个科室每日可预约时段（上午/下午各若干号）
- 挂号：选择科室+时段，生成挂号序号
- 预约规则：同一患者同一天同一科室只能挂 1 个号
- 退号与改约：就诊前 2 小时可免费取消

### 2. 医生排班
- 排班表：按周维护，每天每个科室安排 1-3 名医生
- 医生信息：姓名、职称、专长、手机
- 号源与排班联动：排班自动生成对应号源
- 休班申请：提交 → 科主任审批 → 自动释放号源

### 3. 诊疗记录
- 就诊流程：挂号 → 候诊 → 叫诊 → 开具处方 → 收费 → 取药
- 病历摘要：主诉、现病史、诊断、处方
- 处方：药品列表、用法用量
- 检验申请：血常规、尿常规等，关联检查结果

### 4. 药品库存
- 药品信息：名称、规格、厂家、库存数量、零售价
- 入库出库记录
- 库存预警：低于安全库存自动提醒
- 批次和有效期管理

### 5. 收费结算
- 费用项目：挂号费、诊疗费、药品费、检查费
- 医保结算模拟：自费部分 + 医保报销部分（按比例模拟）
- 日结和月结报表
- 欠费患者记录

## 技术要求
- 使用 Python + FastAPI
- SQLAlchemy ORM + SQLite（单文件）
- Pydantic 模型
- 至少 20 个 API 端点
- 自带种子数据：7 个科室、10 名医生、30 种药品、模拟患者挂号和诊疗记录
- 时间处理注意：使用北京时间，工作日 8:00-17:00

## 交付标准
- `uvicorn app:app --port 8000` 启动
- 挂号-候诊-就诊-收费流程完整
- 医保结算计算逻辑正确
- 药品库存预警正常触发
