# 需求：电商小商店系统 (E-Commerce Shop)

## 项目概述
开发一个面向独立卖家的电商小商店后端，涵盖商品、购物车、订单履约、促销活动和销售分析。支持多规格商品（SKU）和库存管理。

## 核心模块

### 1. 商品与 SKU
- 商品基础信息：标题、分类、品牌、详情（富文本摘要）
- 多规格 SKU：颜色 × 尺寸组合生成 SKU，每个 SKU 独立价格和库存
- 商品状态：`on_sale` / `off_shelf` / `pre_sale`
- 价格体系：原价、售价、会员价
- 商品搜索：关键词 + 分类 + 价格区间 + 排序（销量/价格/上架时间）

### 2. 购物车
- 加入购物车：选规格 → 加数量（库存校验）
- 购物车列表：商品信息、数量、小计
- 促销自动应用：满减、折扣券自动计算最优价格
- 购物车合并：同一商品不同 SKU 合并显示

### 3. 订单管理
- 下单：从购物车生成订单，锁定库存
- 订单状态机：`unpaid` → `paid` → `packed` → `shipped` → `delivered` / `cancelled` / `refunded`
- 订单详情：收货地址、商品明细、支付信息、物流单号
- 订单超时：下单 30 分钟未支付自动取消，释放库存
- 退款申请：退款原因、审核、处理

### 4. 促销引擎
- 满减活动：满 200 减 30、满 500 减 80 等（可叠加）
- 限时折扣：指定商品限时特价
- 优惠券：固定金额券 / 百分比券，每人限领 1 张
- 促销与 SKU 绑定：满减按订单金额、折扣券按商品

### 5. 销售分析 API
- 日/周/月销售额趋势
- 热销商品 Top 10
- 客单均价和转化率（模拟数据）
- 分类销售占比

## 技术要求
- 使用 Python + FastAPI
- SQLAlchemy ORM + SQLite（单文件）
- Pydantic 模型
- 至少 20 个 API 端点
- 自带种子数据：3 个分类、10 个商品（含多规格 SKU 共 40+ SKU）、促销活动和优惠券
- 满减和优惠券计算逻辑必须正确

## 交付标准
- `uvicorn app:app --port 8000` 启动
- 多规格 SKU 选择和库存锁定逻辑正确
- 满减 + 优惠券组合计算正确（找到最优价格）
- 订单状态流转和超时取消正常
